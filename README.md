# AI Studio

موقع ويب يتيح لك اختيار طريقة الإجابة، إرسال نص أو صورة، نسخ الجواب، طلب شرح إضافي، والرجوع إلى سجل الأسئلة المحفوظ في المتصفح.

## المتطلبات
- Node.js 20 أو أحدث.
- مفتاح OpenAI API لاستخدام الذكاء الاصطناعي الحقيقي. استخدام API قد يكلّف مالًا بحسب استهلاكك وإعدادات حسابك.

## التشغيل
1. فك ضغط `ai_studio_project.zip`.
2. افتح Terminal داخل مجلد المشروع.
3. ثبّت الحزم:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى `.env`.
   - macOS/Linux: `cp .env.example .env`
   - Windows PowerShell: `Copy-Item .env.example .env`
5. افتح `.env` وأضف مفتاحك بعد `OPENAI_API_KEY=`.
6. افتح نافذتي Terminal داخل مجلد المشروع:
   - الأولى: `node server.js`
   - الثانية: `npm run dev`
7. افتح رابط Vite الظاهر في النافذة الثانية، غالبًا `http://localhost:5173`.

## الميزات
- خيارات لطريقة الإجابة: الجواب فقط، شرح مبسط، خطوات، أمثلة، أو تلميحات.
- اختيار لغة الإجابة ومستوى التفصيل.
- إدخال نص أو رفع صورة.
- زر نسخ الإجابة وطلب شرح إضافي.
- سجل آخر 30 سؤالًا محفوظ محليًا في المتصفح، مع خيار مسح السجل.

## الأمان والخصوصية
- لا تضع مفتاح API في ملفات الواجهة. ضعه في `.env` فقط، ولا تشارك الملف.
- سجل الأسئلة يُحفظ في `localStorage` داخل المتصفح على هذا الجهاز. لا تحفظ فيه معلومات حساسة.
- الصور والنصوص التي ترسلها تُرسل إلى خادم المشروع ثم إلى مزوّد نموذج الذكاء الاصطناعي لمعالجتها.
- هذه النسخة لا تعدّل كودها بنفسها؛ التحسين الذاتي التلقائي يحتاج نظامًا منفصلًا للاختبار والموافقة قبل نشر تغييرات برمجية.
